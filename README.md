## Introduction
Kanban Board is a web application designed to help teams manage their tasks and workflows using the Kanban methodology. This project is built with a React frontend and a Node.js backend.

## Features
- User authentication
- Create, read, update, and delete tasks
- Drag and drop tasks between columns
- Real-time updates with WebSockets
- Responsive design
